Questions Réponses

2. À quoi sert la propriété CSS display: flex ? Elle active le modèle de boîte élastique (Flexbox), permettant d'aligner et de distribuer l'espace entre les éléments d'un conteneur de manière fluide et responsive.
3. Citez trois balises HTML utilisées dans les formulaires.
  • <input>
  • <textarea>
  • <button>
4. Que produit le code suivant : <h1 style="color:red;">Bienvenue</h1> Il affiche un titre de niveau 1 principal avec le texte "Bienvenue" coloré en rouge.
5. Expliquez la différence entre : id et class Un id est un identifiant unique attribué à un seul élément par page, tandis qu'une class peut être réutilisée sur plusieurs éléments pour leur appliquer le même style.
6. Quelle propriété CSS permet de :
a) changer la couleur du texte ?
b) changer la couleur de fond ?		 a) color
b) background-color
7. À quoi sert l'attribut href dans une balise <a> ? Il sert à indiquer l'URL ou la cible du lien hypertexte vers lequel l'utilisateur sera redirigé.
8. Quelle est la différence entre : une balise bloc (block) et une balise en ligne (inline). Donnez un exemple pour chaque cas.
  • Block : Occupe toute la largeur disponible et commence sur une nouvelle ligne (Ex: <div>, <p>).
  • Inline : Ne prend que la largeur de son contenu et reste sur la même ligne (Ex: <span>, <strong>).
9. Quel est le rôle des balises suivantes : <html>, <head>, <body>
  • <html> : Encapsule tout le contenu de la page web.
  • <head> : Contient les métadonnées et les configurations non visibles (titre, encodage, liens CSS).
  • <body> : Contient la partie visible du site web par l'utilisateur.
10. Définissez les termes suivants : HTML et CSS.
  • HTML : Langage de balisage utilisé pour structurer le contenu d'une page web.
  • CSS : Langage de feuilles de style utilisé pour gérer la présentation et le design du contenu HTML.
